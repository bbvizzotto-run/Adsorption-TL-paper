# Data and licensing policy

No experimental workbook or record-level data are included. Before adding the workbook, derived endpoint observations, row-level manifests, predictions, figures derived from private records, or model weights, obtain explicit permission from all relevant data owners and coauthors and document the applicable data license or access conditions.

The code license and data license are separate decisions. The absence of a data file does not imply that the data are open. If data cannot be redistributed, describe the restrictions and state plainly that independent reproduction of numeric metrics requires authorized access to the data.
