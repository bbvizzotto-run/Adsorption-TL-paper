# Scope and limitations

The code targets prediction of recorded endpoint responses under temperature-held-out evaluation. Endpoint metrics do not validate intermediate kinetic trajectories, kinetic rate constants, transport mechanisms, or equilibrium criteria. Interpret dissolved-metal loss as apparent removal unless adsorption-exclusive attribution is supported by appropriate controls.

No raw or derived experimental observations are distributed in this repository. It is therefore a code snapshot, not a self-contained reproducibility package. Any claims about results must refer to the corresponding approved dataset and frozen run, which are not included here.
